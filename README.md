# Haze

Portfólio de desenvolvimento full stack.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Produção

```bash
npm run build
npm start
```

Defina `NEXT_PUBLIC_SITE_URL` com a URL pública do site para sitemap, robots e metadados absolutos.
